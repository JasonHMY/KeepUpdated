# App icon

`KeepUpdated.icns` contains the standard 16–1024 px macOS icon sizes. Packaging copies it unchanged and declares `CFBundleIconFile` before signing. Its SHA-256 is `666c672a6f071df732aeff51038c3c11cff21ffe42a50fc06f632b9bb8c38cc5`.

The artwork combines an image-generated blue tile and a geometric white update ring. The promotional film is not required to build the App.
