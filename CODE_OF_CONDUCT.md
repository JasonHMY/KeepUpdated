# Code of Conduct

Contributors of different backgrounds and experience levels are welcome. Keep discussions focused on the problem, evidence and code, and respect each other's time and judgment. Disagreement is welcome; explain your reasons clearly.

Do not engage in personal attacks, harassment, discrimination, threats or spam, or expose someone else's private information. Review the code rather than judging the person. When you find a mistake, help explain the problem and how to fix it.

These expectations apply to Issues, PRs, code reviews and other project discussions. Maintainers may explain the rules, request changes, hide inappropriate content or close off-topic discussions. Responses should be proportionate to the situation.

To report misconduct, use the report option beside the content on GitHub, following [GitHub's reporting guidance](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Do not spread private information again in a public argument. Product vulnerabilities use the separate private channel in [SECURITY.md](SECURITY.md).
